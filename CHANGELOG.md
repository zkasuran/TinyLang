# Changelog

All notable changes to TinyLang are documented here.

## [1.0.0] - 2026-08-22

### Added
- Complete language implementation (lexer, parser, interpreter)
- 6 data types: number, string, boolean, null, array, object
- Variables with `let` (mutable) and `const` (immutable)
- Functions with default parameters and closures
- Arrow function syntax `(x) => x * 2`
- Classes with inheritance via `extends`
- Control flow: if/else, while, for-in, match/when, break, continue
- Range expressions `0..10` for concise iteration
- Standard library with 60+ built-in functions
- Interactive REPL with multi-line support and dot commands
- CLI tool with run, repl, check, version, help commands
- Web Playground (single HTML file, no server needed)
- 124 passing tests (lexer, parser, interpreter, integration)
- 10 example programs teaching progressive concepts
- Educational error messages with hints
- Complete Kiro configuration (specs, steering, hooks)
- Comprehensive documentation and README
